# カレンダー購読フィード (Google Apps Script)

活動計画表 (`minamigaoka_schedule.html`) の予定を、Googleカレンダーなどで購読できる iCalendar 形式で配信する Apps Script です。
Firestore の `app/main` を読み取るだけで、データは書き換えません。

## 設置手順

1. フィードを管理する Google アカウント (チーム共用アカウント推奨) で https://script.google.com を開き、「新しいプロジェクト」を作る
2. プロジェクト名を「南ヶ丘MBC カレンダー購読」などに変更
3. `コード.gs` の中身を消して、`calendar_feed.gs` の内容を貼り付けて保存
4. ⚙️「プロジェクトの設定」→ タイムゾーンを「(GMT+09:00) 日本標準時 - 東京」にする
5. 「デプロイ」→「新しいデプロイ」→ 種類の選択で「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. 「デプロイ」を押し、権限の確認画面で許可する (外部サービスへの接続の許可を求められます)
7. 表示された「ウェブアプリのURL」(`https://script.google.com/macros/s/.../exec`) をコピー
8. `minamigaoka_schedule.html` の `const CAL_FEED_URL = '';` にそのURLを設定する

ブラウザでURLを開いて `BEGIN:VCALENDAR` から始まる文字が表示されれば成功です。

## コードを更新したとき

「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新しいバージョン」→「デプロイ」。
この方法なら URL は変わりません (「新しいデプロイ」を作ると URL が変わるので注意)。

## URLパラメータ

| パラメータ | 内容 | 例 |
|---|---|---|
| `types` | 含める種類 (カンマ区切り)。省略時はすべて | `match,league,duty` |
| `member` | メンバーID。その人が担当のお当番・鍵当番だけにする | `abc123` |
| `names` | `1` でお当番・鍵当番のメンバー名を含める (既定は含めない) | `1` |

種類: `practice`(練習) / `match`(練習試合) / `league`(大会試合) / `other`(その他) / `duty`(お当番) / `key`(鍵当番)

過去60日分以降の予定を配信します。Firestore の読み取り結果は5分間キャッシュします。
